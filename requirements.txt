# QQ 官方 bot 语音条（silk）所需依赖 —— 由 KiraAI 插件加载器自动安装。
#
# ══════════════════════════════════════════════════════════════════════════
# ★ 为什么需要这些（2026-10-08 查证 + 实测）
# ══════════════════════════════════════════════════════════════════════════
#
# **ffmpeg 本身压不出 silk**：
#     ffmpeg -encoders | grep silk   →  空
#     ffmpeg -decoders | grep silk   →  空
#     ffmpeg ... -c:a silk out.silk  →  Unable to choose an output format
#   Silk 是 Skype 的专有编解码器，ffmpeg **只能解、不能编**。
#
# 所以链路必须分两步：
#
#     mp3/wav/ogg ──① 解码成 PCM──> PCM ──② 编码成 silk──> silk
#
#   ① 用 ffmpeg（见下面 imageio-ffmpeg；系统已有 ffmpeg 时**优先用系统的**）
#   ② 用下面这几个 silk 编码器之一
#
# ── 关于 silk 编码器的选择（这里踩过坑）───────────────────────────────
#
# 原来只写了 `pilk`，但它的 Windows wheel **只到 cp311**（36/37/38/39/310/311）。
# 用 Python 3.12+ 的机器（例如 KiraAI 自带的 3.13）pip 会去**编译源码**，
# 而 Windows 上编译需要 Visual C++ Build Tools ⇒ 报错：
#
#     error: Microsoft Visual C++ 14.0 or greater is required.
#     ERROR: Failed building wheel for pilk
#
# ⇒ 现在**首选 `silk-python`**，它的 wheel 覆盖 **cp38–cp314**（含 cp313），
#    在 py3.12/3.13 上**直接装预编译包，不需要编译器**。
#    它同样是 `silk-v3-decoder` 的绑定（支持腾讯系 silk）。
#
# 三个后端都留着，代码会自动选**能用的那个**（见 audio_silk.py）：
#     1) silk-python（pysilk）—— wheel 覆盖最广，**首选**
#     2) pilk                 —— 老牌，cp311 及以下可用
#     3) silk_v3_encoder      —— 外部可执行文件（如果用户自己装了）
#
# 注意：这几个**不是硬依赖** —— 全装不上时插件会**自动退回「按文件发送」**，
#       功能降级但绝不报错、绝不丢消息。
# ──────────────────────────────────────────────────────────────────────

# ① silk 编码器（三选一即可，优先第一个）
silk-python>=0.2.8      ; python_version >= "3.8"
pilk>=0.2.4             ; python_version < "3.12"

# ② 图片格式规范化（把 GIF/WEBP 转成 PNG）—— 平台上传接口只收 png/jpg，
#    GIF 直传实测会被拒：400 850019 富媒体文件格式不支持。
#    没有 Pillow 时插件不会报错，只是这类图片仍会失败（日志会说明）。
Pillow>=9.0.0

# ③ ffmpeg（带静态二进制的 pip 包；**系统已有 ffmpeg 时会优先用系统的**）
imageio-ffmpeg>=0.5.1
